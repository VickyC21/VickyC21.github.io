# PyTorch 训练问题定位讲义：维度、梯度、NaN、OOM 与不收敛

本讲义面向刚开始做深度学习和大模型训练的开发者。训练排障的关键不是记忆报错，而是按数据、前向、损失、反向、参数更新、验证和显存这条链路逐段验证。

## 1. 总体方法：先证明，再修改

训练 step 的链路是：

~~~text
数据 -> x/y -> 模型 output -> loss -> backward() -> optimizer.step() -> 指标
~~~

| 现象 | 优先检查位置 | 常见根因 |
| --- | --- | --- |
| 维度错误 | 数据、模型输入、损失函数 | shape、dtype、类别数、维度顺序不匹配 |
| 梯度不更新 | backward 到 step | 漏掉调用、断开计算图、参数未进优化器 |
| NaN / Inf | 输入、前向、loss、梯度、参数 | 非法数值、学习率过大、FP16 溢出 |
| OOM | 前向、反向、日志、验证 | batch/序列过大、保存计算图、模型状态过大 |
| 不收敛 | 全链路 | 数据/标签错、目标错、超参数不合适 |

一次只验证一个假设。不要同时改 batch size、学习率、模型和损失函数，否则即使结果变好，也无法确认原因。

推荐顺序：保存配置、随机种子和日志；只检查一个 batch；对 32 到 128 条样本做过拟合测试；证明参数在更新；定位第一个异常 step；最后再调参。

## 2. 通用调试工具

~~~python
import torch
from torch import nn


def describe_tensor(name: str, tensor: torch.Tensor) -> None:
    """输出张量形状、类型、设备和有限性。"""
    print(
        f"{name}: shape={tuple(tensor.shape)}, "
        f"dtype={tensor.dtype}, device={tensor.device}, "
        f"requires_grad={tensor.requires_grad}, "
        f"finite={torch.isfinite(tensor).all().item()}"
    )


def check_finite(name: str, tensor: torch.Tensor) -> None:
    """在第一个 NaN 或 Inf 出现的位置停止。"""
    if not torch.isfinite(tensor).all():
        raise FloatingPointError(f"{name} 包含 NaN 或 Inf")


def grad_norm(model: nn.Module) -> float:
    """计算已有梯度参数的全局 L2 范数。"""
    total = 0.0
    for parameter in model.parameters():
        if parameter.grad is not None:
            total += parameter.grad.detach().float().norm(2).item() ** 2
    return total ** 0.5
~~~

首次训练前，检查一个 batch：

~~~python
x, y = next(iter(train_loader))
describe_tensor("x", x)
describe_tensor("y", y)

x, y = x.to(device), y.to(device)
output = model(x)
describe_tensor("output", output)
loss = criterion(output, y)
describe_tensor("loss", loss)
~~~

这能确认 shape、dtype、device、输出和 loss 是否满足基本约定。

## 3. 数据维度错误

每一维都要有明确语义：B 是 batch，F 是特征数，C 是类别数，T 是序列长度，V 是词表大小。

| 场景 | 输入 x | 输出 | 标签 y |
| --- | --- | --- | --- |
| 多分类 | [B, F] | [B, C] logits | [B]，long |
| 图像分类 | [B, C, H, W] | [B, C] logits | [B]，long |
| 回归 | [B, F] | [B] 或 [B, 1] | 与输出同 shape，float |
| 语言模型 | [B, T] | [B, T, V] logits | [B, T]，long |

### 3.1 多分类

CrossEntropyLoss 接受原始 logits 和类别索引标签：

~~~python
logits = torch.randn(4, 3)
targets = torch.tensor([0, 2, 1, 0], dtype=torch.long)
loss = nn.CrossEntropyLoss()(logits, targets)
~~~

不要在模型结尾添加 Softmax 后再交给 CrossEntropyLoss。只有展示概率或推理时才写 torch.softmax。

### 3.2 二分类

BCEWithLogitsLoss 要求输出与标签 shape 完全一致，标签通常是 float：

~~~python
logits = torch.randn(4, 1)
targets = torch.tensor([[1.0], [0.0], [1.0], [0.0]])
loss = nn.BCEWithLogitsLoss()(logits, targets)
~~~

[B, 1] 与 [B] 可能发生广播并悄悄给出错误结果。显式对齐，且用 squeeze(1) 而非无参数 squeeze()：

~~~python
logits = logits.squeeze(1)
targets = targets.squeeze(1)
assert logits.shape == targets.shape
~~~

### 3.3 图像和语言模型

PyTorch 卷积层使用 NCHW；若数据是 HWC，需要转换：

~~~python
images = images.permute(0, 3, 1, 2).contiguous()
~~~

自回归语言模型预测下一个 token，标签必须左移：

~~~python
shift_logits = logits[:, :-1, :].contiguous()
shift_labels = input_ids[:, 1:].contiguous()
loss = nn.functional.cross_entropy(
    shift_logits.view(-1, shift_logits.size(-1)),
    shift_labels.view(-1),
)
~~~

忘记 shift 未必报错，但模型会学习复制当前 token。padding 或不应学习的位置应设为 -100，并使用 ignore_index=-100。

维度排查前逐项回答：每轴是什么、batch 是否在第 0 维、模型配置与数据是否一致、标签语义和 dtype 是否正确、是否因 squeeze/transpose/reshape 改坏了语义、广播是否掩盖错误。

## 4. 梯度不更新

标准训练 step：

~~~python
model.train()
optimizer.zero_grad(set_to_none=True)
output = model(x)
loss = criterion(output, y)
loss.backward()
optimizer.step()
~~~

直接证明参数变化：

~~~python
before = [p.detach().clone() for p in model.parameters()]

optimizer.zero_grad(set_to_none=True)
loss = criterion(model(x), y)
loss.backward()
optimizer.step()

after = [p.detach() for p in model.parameters()]
assert any(not torch.equal(old, new) for old, new in zip(before, after))
~~~

高频根因：漏掉 backward 或 step；创建优化器后替换了模型层；参数 requires_grad=False；模型输出调用 detach()；把 Tensor 用 torch.tensor() 重新构造；训练前向被 torch.no_grad() 包裹；梯度累积时漏清梯度或漏掉最后一次 step。

训练完成模型后再创建优化器。微调时确认目标 adapter 位于优化器参数组中。反向后检查梯度：

~~~python
for name, parameter in model.named_parameters():
    if parameter.grad is None:
        print(f"{name}: grad=None")
    else:
        print(f"{name}: grad_norm={parameter.grad.detach().norm().item():.6g}")
~~~

grad=None 通常表示参数没有参与计算图或被冻结；全 0 表示可能没有有效学习信号；极大梯度预示数值爆炸。

## 5. NaN 与 Inf

第一个非法值的位置比最后的报错更重要：输入坏，查数据和归一化；output 坏，查初始化、激活和输入范围；loss 坏，查标签和损失定义；grad 坏，查学习率、梯度爆炸和混合精度；参数在 step 后坏，查优化器与梯度。

~~~python
# 风险：标准差可能为 0
x = (x - x.mean()) / x.std()

# 数值保护
x = (x - x.mean()) / x.std().clamp_min(1e-6)

eps = 1e-8
log_value = torch.log(probability.clamp_min(eps))
ratio = numerator / denominator.clamp_min(eps)
distance = torch.sqrt(squared_distance.clamp_min(0))
~~~

不要手写 sigmoid 后再 log 的二分类交叉熵，使用稳定实现：

~~~python
loss = nn.functional.binary_cross_entropy_with_logits(logits, target)
~~~

若 loss 初期正常、随后爆炸，先保持其他条件不变，将学习率缩小 10 倍做短实验。梯度裁剪位于 backward 与 step 之间：

~~~python
loss.backward()
norm = torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
optimizer.step()
~~~

FP16 使用 GradScaler 时，裁剪前先 scaler.unscale_(optimizer)。BF16 范围更大，但不能修复错误数据或公式。

## 6. OOM：先判断哪种内存在增长

训练显存包括参数、梯度、优化器状态、激活、输入和临时张量。每步后持续增长通常说明保存了计算图；首次前向就 OOM 通常说明 batch、序列长度或模型规模过大。

最常见泄漏：

~~~python
# 错误：loss 携带整张计算图
loss_history.append(loss)

# 正确：日志只保留标量
loss_history.append(loss.detach().item())
~~~

验证阶段必须关闭梯度：

~~~python
model.eval()
with torch.inference_mode():
    for x, y in val_loader:
        output = model(x)
~~~

处理顺序：检查带图 Tensor；关闭验证梯度；降低 batch；降低 max_length 或做长度分桶；使用梯度累积、BF16/FP16、梯度检查点；冻结参数或用 LoRA/QLoRA；最后考虑 FSDP、ZeRO 等分布式方案。

torch.cuda.empty_cache() 只能释放未被引用的缓存，不能修复泄漏。Transformer 注意力的显存常随序列长度近似二次增长，因此缩短 max_length 往往比降低 batch 更有效。

## 7. 训练不收敛

“不收敛”可能指 loss 不降、剧烈震荡、训练好验证差、长期随机水平，或 loss 降了但业务指标不变。先做小数据过拟合：

~~~python
tiny_subset = torch.utils.data.Subset(train_dataset, list(range(64)))
tiny_loader = torch.utils.data.DataLoader(tiny_subset, batch_size=64, shuffle=True)

for epoch in range(200):
    for x, y in tiny_loader:
        x, y = x.to(device), y.to(device)
        optimizer.zero_grad(set_to_none=True)
        loss = criterion(model(x), y)
        loss.backward()
        optimizer.step()
~~~

失败时优先检查输入与标签是否配对、输出和损失是否匹配、参数是否更新、标签范围、学习率与模型容量。

固定数据、模型、batch、种子，只比较 1e-5、1e-4、1e-3 等学习率的相同步数；记录 loss、grad_norm、NaN 和验证指标。没有万能学习率，从零训练、全参微调和 LoRA 的合理范围不同。

训练和验证模式必须分开：训练用 model.train()，验证用 model.eval() 加 torch.inference_mode()。训练损失降、验证损失升通常是过拟合；两者都不降时优先怀疑实现、数据、学习率或容量；训练低验证高时检查数据泄漏、切分分布和预处理一致性。

## 8. 大模型微调与复盘

LoRA 训练前打印 requires_grad=True 的参数名和数量，必须看到预期 adapter 且数量不为 0。监督微调中提示词、padding 或不应学习的位置应设为 -100。记录 token 长度分布，少数超长样本可造成偶发 OOM。DDP、FSDP、ZeRO 不会修复错误标签、NaN 或断图，应先让单卡最小复现通过。

最小日志包含：epoch、global_step、train_loss、val_loss、学习率、grad_norm、batch/有效 batch、最大序列长度、峰值显存、数据与模型版本。

每次排障应记录：现象、证据、根因、最小修复、验证方法、剩余风险。

训练调试的核心不变量：

- 输入、输出、标签的 shape、dtype、device 与语义一致；
- 可训练参数进入计算图、得到梯度并由优化器更新；
- 输入、输出、loss、梯度和参数都是有限数；
- 计算图不被日志长期持有；
- 先在小数据上过拟合，再讨论规模与泛化；
- 每次修改都有明确证据和最小验证。
